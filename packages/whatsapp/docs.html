Detalle por Modulo

config.ts -- Tipos y Defaults

ExportTipoDescripcion
WhatsAppButtonConfiginterfaceTodas las propiedades configurables (companyToken, phone, label, color, textColor, position, message, lang, chatIdStrategy, mode, webhookUrl, openInNewTab, scope)
TrackingDatainterfacePayload del webhook: chatId, url, device, gclid, + params dinamicos
DEFAULTSconstValores por defecto: label "Contactanos", color #25D366, position bottom-right, strategy url, mode float
parseDataAttributes()functionLee dataset de un HTMLElement y retorna Partial<WhatsAppButtonConfig>
mergeConfig()functionCombina defaults + overrides del usuario, elimina undefined

chat-id.ts -- Generador de ID

ExportTipoDescripcion
generateChatId()functionGenera 5 caracteres alfanumericos (A-Za-z0-9). Usa crypto.getRandomValues() con fallback a Math.random()

Charset: 62 caracteres. Combinaciones posibles: 62^5 = 916,132,832. Suficiente para evitar colisiones en volumen tipico de leads.

tracking.ts -- Recoleccion de Datos

ExportTipoDescripcion
detectDevice()functionRetorna "mobile" | "tablet" | "desktop" | "unknown". Prioridad: URL param ?device= > UA regex > screen width
getGclid()functionExtrae gclid de ?gclid= en URL, o de cookie _gcl_aw. Retorna undefined si no existe.
collectTrackingData()functionCompone el payload completo: genera chatId, lee URL params, detecta device y gclid. Retorna TrackingData.

button.ts -- Orquestador Principal

ExportTipoDescripcion

initWhatsAppButton()functionEntry point principal. Resuelve locale, merge config, elige modo (float/attach), retorna cleanup.

Modo float (default)

Renderiza boton flotante + adjunta comportamiento a [data-atom-button] existentes.

Modo attach

Solo adjunta comportamiento a [data-atom-button] existentes. No crea UI.
