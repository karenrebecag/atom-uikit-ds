# 001 — ATOM/academy es el lenguaje visual web oficial

- **Status:** accepted  
- **Date:** 2026-07-28  
- **Context:** Marketing aprobó Atom Academy (ATOM-inspired) como look de sitios oficiales.  
- **Decision:** Primitives + semantic mapping del UIKit adoptan ATOM; **cero renames** de tokens semánticos (migración non-breaking).  
- **Consequences:** Tipografías Inter Tight / Grift / Interval / Gantol; neutral 150/850; acentos electric/forest/coral/sky; brand `#ff6600`. Brandbook Grift-first se formaliza como estándar web.
